## 🌟 Executive Overview

**Lumora Fine Jewelry** is an enterprise-grade, full-stack luxury e-commerce platform custom engineered for Indian fine jewelry exporters selling direct-to-consumer (D2C) to North American clients.

By bypassing multi-tier wholesale brokers and traditional 400%–500% Fifth Avenue luxury boutique retail markups, Lumora delivers solid 9K, 14K, and 18K gold and 925 sterling silver heirlooms direct from master jewelers in Jaipur and Surat to customer doorsteps across the United States and Canada in **3–5 business days via DHL Express Worldwide and FedEx Priority**.

## 💳 Indian Merchant Payment & Export Architecture

The backend is built specifically for an Indian registered business exporting goods to US and Canadian buyers:

1. **Stripe India Export Mode**:
   - Configured with Reserve Bank of India (RBI) Purpose Code: **`P0103 - Export of Goods`**.
   - Generates automated monthly **e-FIRA / FIRC** certificates for bank and customs realization.
   - Mandatory overseas shipping address collection strictly restricted to `['US', 'CA']`.
   - Charge currencies: USD and CAD supported directly.
2. **Server-Side Security & Idempotency Guarantee**:
   - Stripe credentials remain strictly on the server (`STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`).
   - Webhook endpoint (`/api/webhooks/stripe`) validates cryptographic signatures (`stripe.webhooks.constructEvent`).
   - **Idempotency Protection**: Every transaction token or Stripe event ID is recorded in the persistent `processedWebhooks` store. Repeated payment notifications **cannot create duplicate orders or deduct inventory multiple times**.
3. **Verified Server Test Mode**:
   - When Stripe API keys are not provided in `.env`, the system runs in an automated Test Mode that generates verified orders, maintains stock levels, and permits end-to-end checkout testing.

## 🗄️ Persistent Database Layer

Data is stored persistently in `server/data/database.json` with synchronous atomic write safeguards (`.tmp` flush and rename):
- `products`: Complete catalog with variants, stock levels, metal purities, and lab-diamond specifications.
- `orders`: Customer details, address, tracking number, CSB-V number, and fulfillment timeline.
- `discounts`: Promotional codes, discount types, values, and minimum spend thresholds.
- `settings`: Return window (30 days), shipping rates, Canadian duty mode (DDP/DDU), and export compliance credentials.
- `processedWebhooks`: Idempotency tracking table.
